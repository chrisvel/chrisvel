## What I build

**[tududi](https://tududi.com)** is a self-hosted task and project manager:
tasks, projects, notes, areas, habits, 25 languages. It ships an MCP server, so an AI agent
connects to your own instance and nothing routes through anybody else's server.
[Docs](https://docs.tududi.com) &middot; [Hosted](https://cloud.tududi.com) &middot;
[Source](https://github.com/chrisvel/tududi)

**[reconYa](https://reconya.com)** is network reconnaissance in Go.
It sweeps your subnet, fingerprints what answers and keeps a live map, so the device that
appeared on your LAN at 3am does not stay a mystery until morning. No Docker support yet:
scanning from inside a container needs host networking to reach the LAN, and that is not
fully solved.
[Source](https://github.com/Dyneteq/reconya)

**[Breach Harbor](https://breachharbor.com)** is one small program for a Linux
server. It reads the log files you already have, works out who is trying to break in, and
blocks them. For the first 24 hours it blocks nothing and only shows you what it would have
blocked, so you can check it before you trust it. Early.
[Source](https://github.com/Dyneteq/Breach-Harbor)

**[oblivYon](https://chrisveleris.com/projects/rc-to-ugv-pt1/)** is a 4WD rover built from
parts: a Raspberry Pi Pico, a motor driver, ultrasonic sensors. Motor control and RC control
work. The chassis does not, which is the true state of it.

Covered by XDA Developers and GIGAZINE. Listed in awesome-selfhosted.
